# 용량정산금 데이터 조사 및 프로젝트 적용안

작성일: 2026-11-10
대상 프로젝트: 제주 재생에너지 가상 포트폴리오·ESS 운영계획
기존 백테스트 기간: 2024-06-01 ~ 2025-12-31

## 1. 결론

현재 확보한 자료와 추가로 확인한 KPX 답변을 이용하면, 2024-07-01 이후 구간에는 단순한 설비용량 곱셈보다 정확한 **시간별 용량정산금 계산기**를 적용할 수 있습니다. 다만 2024년 6월 실효용량비율과 실제 입찰·계량 자료가 아직 없어, 2024-06-01~06-30 및 공식 최종 정산금 전체를 완전히 재현할 수는 없습니다.

이번 프로젝트의 1차 적용에는 다음 자료를 사용합니다.

1. 거래기간에 맞는 제주 기준용량가격(RCP)
2. 월별 실효용량비율 중 프로젝트 ESS에 해당하는 4시간 열의 값
3. 프로젝트의 입찰·낙찰 가정(현재 팀에서 검토 중인 100/90/80% 시나리오)
4. 포트폴리오의 태양광·풍력 설비용량과 ESS 용량

정확한 과거 정산 재현을 위해서는 추가로 2024년 6월의 실효용량비율, 실제 입찰·낙찰·계량·급전지시 자료가 필요합니다. 특히 2026년 4월 개편으로 RPCF가 도입되었으므로, 2024~2025년 백테스트에 2026년 RPCF를 그대로 적용하면 안 됩니다.

## 2. 프로젝트에 바로 사용할 수 있도록 수집한 데이터

### 2.1 기준용량가격(RCP)

제주 발전기의 기준용량가격은 이번에 확인한 적용기간에서 모두 **22.05원/kWh**입니다. 적용기간은 다음과 같이 분리해 두었습니다.

| 적용 기간 | 제주 RCP | 프로젝트 백테스트 적용 |
|---|---:|---|
| 2023/2024 | 22.05원/kWh | 2024-06-01 ~ 2024-06-30 |
| 2024/2025 | 22.05원/kWh | 2024-07-01 ~ 2025-06-30 |
| 2025/2026 최초 공시 | 22.05원/kWh | 2025-07-01 ~ 2025-11-14 |
| 2025/2026 변경 공시 | 22.05원/kWh | 2025-11-15 ~ 2025-12-31 |

RCP 자체는 기간별 값이 같으므로 수치 변화는 없지만, 공식 공시의 적용기간을 분리해 두어 규칙 변경이나 추후 값 변경에 대응할 수 있게 했습니다.

저장 파일: [`rcp_jeju_by_period.csv`](../../data/processed/capacity_settlement/rcp_jeju_by_period.csv)

### 2.2 실효용량비율

실효용량비율은 설비용량 중 용량정산에 인정되는 비율입니다. 공식 자료에는 태양광, 풍력, ESS 2·4·6·8시간 열이 따로 공시되어 있습니다.

현재 프로젝트의 ESS 가정은 16 MWh / 4 MW이므로 단순 환산상 4시간 ESS입니다. 따라서 ESS를 용량정산 대상 자원으로 직접 반영하는 경우에는 우선 `ess_4h_pct`를 사용합니다. 다만 이것은 현 프로젝트의 설비 선정 결과가 아니라 기존 모델의 가정이므로, 실제 ESS 사양이 정해지면 다시 산정해야 합니다.

수집한 파일에는 2024/2025, 2025/2026, 2026/2027 적용기간의 월별 값이 들어 있습니다. 2024~2025 백테스트에는 앞의 두 적용기간만 사용하고, 2026/2027 자료는 최신 참고자료로만 보관합니다.

저장 파일: [`effective_capacity_ratio_jeju.csv`](../../data/processed/capacity_settlement/effective_capacity_ratio_jeju.csv)

## 3. 확인된 공식 산식과 구현

KPX의 2024년 제주 정산교육자료와 2024년 10월 질의응답은 제주 재생e의 용량정산금을 다음과 같이 설명합니다.

```text
시간별 용량정산량(MWh)
  = min(발전량(MWh), 입찰량(MWh), 실효용량(MW) × 시간(h))

시간별 용량정산금(원)
  = 시간별 용량정산량(MWh) × 1,000 × RCP(원/kWh)
```

KPX의 예시에서도 발전시간이 4시간이면 24시간 전체가 아니라 발전하는 시간에 대해서만 `min(발전량, 입찰량, 실효용량)`을 계산한다고 답변했습니다. 즉, 이번 프로젝트에서는 발전량이 없는 시간에 용량정산금을 자동으로 지급하는 방식으로 계산하지 않습니다.

다만 정산교육자료의 상세식에는 `SET_POINT`, 공급가능용량, 변경 공급가능용량이 추가로 등장합니다. `SET_POINT = RA`인 경우 발전량까지 최소값에 포함하고, 그렇지 않은 경우에는 발전량을 별도로 최소값에 넣지 않는 분기가 제시됩니다. 현재 프로젝트에는 이 세 가지 실제 입찰·급전 값이 없으므로, 구현 모듈은 우선 KPX Q&A에서 질문된 기본 시나리오인 `min(발전량, 입찰량, 실효용량)`을 계산하고, 해당 한계를 결과에 남깁니다.

구현 파일: [`capacity_settlement.py`](../../src/vpp/capacity_settlement.py)
검증 테스트: [`test_capacity_settlement.py`](../../tests/test_capacity_settlement.py)

원문 PDF도 [`jeju_settlement_education_2024.pdf`](../references/capacity_settlement/jeju_settlement_education_2024.pdf)로 보관했습니다.

구현된 계산 절차는 다음과 같습니다.

1. 날짜와 월을 기준으로 RCP 및 실효용량비율 적용기간을 매칭합니다.
2. 태양광과 풍력을 분리해 각각 설치용량과 발전량을 적용합니다.
3. `effective_capacity = installed_capacity × ratio / 100`을 계산합니다.
4. 현재 실제 입찰량이 없으므로 `installed_capacity × acceptance_rate`를 입찰량 시나리오로 사용합니다.
5. 매 시간 `min(발전량, 입찰량, 실효용량)`을 계산하고 원/kWh 단위로 변환합니다.
6. 참조자료가 없는 기간은 0원으로 처리하지 않고 오류 또는 `NaN`으로 남깁니다.

추가로 `kpx_capacity_quantity_mwh` 함수에는 정산교육자료의 `SET_POINT = RA` / `SET_POINT < RA` 분기를 구현했습니다. 향후 실제 `A`, `RA`, `MGO`, `EA`, `SET_POINT`가 들어오면 현재의 시나리오용 계산기 대신 이 분기를 이용해 공식식에 더 가깝게 계산할 수 있습니다.

현재 코드의 16 MWh / 4 MW ESS는 `docs/formulation.md`에 설비 근거가 없는 가정값으로 명시되어 있습니다. 또한 현재 모델은 태양광·풍력 발전량과 SMP를 이용한 ESS 운영계획만 계산하고, 용량정산금은 아직 목적함수나 사후 평가에 포함하지 않습니다. 그러므로 1차 구현에서는 먼저 `capacity_revenue_krw`를 사후 평가 결과에 추가하고, 용량정산금이 실제 운전 의사결정에 영향을 주는지 확인하는 순서가 안전합니다.

## 4. 추가로 필요한 데이터와 이유

| 데이터 | 현재 상태 | 필요한 이유 | 우선순위 |
|---|---|---|---|
| 실제 입찰용량·낙찰용량·인정용량 | 없음. 팀 논의상 100/90/80% 시나리오 사용 예정 | 실제 용량정산 대상량을 결정 | 높음 |
| 공급가능용량(A), 변경 공급가능용량(RA), SET_POINT | 없음 | 정산교육자료의 분기 산식을 정확히 적용 | 높음 |
| 시간별 계량 발전량·가용용량 | 발전량은 일부 보유하지만 용량정산용 자원별 가용성 자료는 없음 | 실효용량과 인정량을 거래시간별로 계산 | 높음 |
| 급전지시 여부 및 급전지시량 | 없음 | 2026년 개편 규칙은 급전지시 여부에 따라 허용오차가 달라짐 | 높음 |
| 거래기간별 시간대/시간별 계수 | 아직 미수집 | RCP만 곱하면 공식 정산금과 차이가 날 수 있음 | 높음 |
| 2024~2025년 역사적 RPCF 또는 그에 대응하는 계수 | 없음 | RPCF는 2026-04 개편 이후 자료이므로 과거 기간에 별도 계수가 필요할 수 있음 | 높음 |
| 자원 등록형태와 용량정산 주체 | 없음 | 태양광·풍력 개별자원, VPP 집합자원, ESS 보조자원의 중복계상을 방지 | 높음 |
| 실제 정산서 또는 KPX 정산 결과 | 없음 | 모델 결과를 공식 금액과 검증 | 중간 |
| ESS 실제 정격용량·출력·운전가능시간 | 현재는 16 MWh / 4 MW 가정 | 2/4/6/8시간 실효용량비율 선택과 인정용량 계산 | 중간 |
| 출력제어·운전불가·통신불가 이력 | 없음 | 가용용량과 실제 인정량을 낮추는 사건 반영 | 중간 |

특히 `자원 등록형태와 용량정산 주체`가 중요합니다. 현재 프로젝트는 태양광 18곳과 풍력 3곳을 합산하고 ESS 1대가 전체에 접근한다고 가정하지만, 이것이 공식 시장에서 하나의 집합자원으로 등록되었다는 뜻은 아닙니다. 따라서 현재 구현은 **재생 발전자원(PV·풍력) 용량정산금만 계산**하며, ESS 용량정산금을 별도로 더하지 않습니다. 발전자원 용량에 용량정산금을 계산한 뒤 ESS 용량정산금을 별도로 더하면 중복계상이 될 수 있습니다.

참고로 2024년 9월에는 제주 VPP 내 비중앙급전 ESS의 실효용량을 발전자원과 분리하자는 규칙개정안이 제출되었지만 부결되었습니다. 따라서 이 제안식은 연구 참고자료로는 활용할 수 있어도, 현재 프로젝트의 2024~2025년 공식 정산식으로 확정해 적용하면 안 됩니다.

## 5. 2024~2025 백테스트에 대한 권장 적용 순서

### 1단계: 사후 수익 항목으로만 추가

- 거래일별 RCP를 적용기간으로 매핑합니다.
- 2024/2025 및 2025/2026 실효용량비율의 해당 월 값을 불러옵니다.
- ESS는 일단 4시간 열을 사용하되, `assumption_not_equipment_spec`로 표시합니다.
- 입찰·낙찰량은 기존 팀 논의대로 100/90/80% 시나리오로 계산합니다.
- 결과에 `capacity_revenue_krw`, `capacity_assumption_version`, `capacity_data_source`를 추가합니다.

### 2단계: 중복계상 여부 확인

- 용량정산 대상이 포트폴리오의 태양광·풍력인지, VPP 집합자원인지, ESS 보조자원인지 확인합니다.
- 동일한 MW에 대해 발전자원과 ESS 용량정산금을 동시에 더하지 않습니다.
- ESS가 용량정산의 직접 대상이 아니라면 ESS 용량정산금은 0으로 두고, 발전자원 또는 집합자원 기준으로 계산합니다.

### 3단계: 정확한 정산 재현이 필요할 때 보강

- 2024-06~2025-12 각 거래일에 적용된 전력시장운영규칙 버전을 확정합니다.
- 해당 버전의 용량가격·실효용량·시간대 계수 표를 확보합니다.
- 실제 입찰량, 낙찰량, 계량량, 가용량, 급전지시와 정산결과를 연결합니다.
- 그 다음에야 용량정산금을 목적함수에 넣을지 결정합니다. 용량정산금이 용량 자체에만 비례하고 운전상태와 무관하다면 사후 계산으로 충분하지만, 가용성·SOC·급전이 인정량을 바꾸면 최적화 제약에도 반영해야 합니다.

## 6. 2026년 자료의 사용 범위

2026년 4월 1일부터 KPX는 용량정산을 개편하여 24시간 실효용량 기준과 계통기여도에 따른 RPCF를 도입했습니다. 2026년 10월에는 실효용량계수 변동성과 RPCF 계산·적용 시점 차이를 보완하는 개정안도 공고되었습니다. 따라서 2026년 RPCF 자료는 **최신 제도 참고 및 향후 기간 시나리오**로는 유용하지만, 현재 프로젝트의 2024-06~2025-12 결과에 그대로 적용할 데이터는 아닙니다.

이번에 수집한 2026년 하반기 RPCF는 참고용 CSV로 저장했습니다.

저장 파일: [`rpcf_2026_2_reference.csv`](../../data/processed/capacity_settlement/rpcf_2026_2_reference.csv)

정확한 거래자료를 받으면 채울 수 있도록 [`kpx_capacity_input_template.csv`](../../data/processed/capacity_settlement/kpx_capacity_input_template.csv)도 추가했습니다. `available_mwh`는 A, `bid_mwh`는 RA, `metered_mwh`는 MGO, `effective_capacity_mwh`는 EA에 대응하며, `set_point_mwh`가 있으면 공식 분기를 적용할 수 있습니다.

## 8. 현재 판단

지금 단계에서 가장 합리적인 범위는 **시간별 `min(발전량, 입찰량, 실효용량) × RCP` 계산 + 100/90/80% 입찰량 시나리오**입니다. 2024-07-01 이후에는 이 계산기를 이용해 자원별 사후 민감도 분석을 진행할 수 있습니다. 2024년 6월은 실효용량비율을 추가 확보하기 전까지 별도 누락 구간으로 표시해야 합니다.

따라서 다음 검토 사항은 데이터 수집 자체보다 먼저, 팀에서 “용량정산 대상이 발전자원인지, 집합자원인지, ESS까지 포함하는지”를 확정하는 것입니다. 이 결정이 정해져야 어떤 용량에 실효용량비율을 곱할지와 중복계상 방지 규칙을 확정할 수 있습니다.
