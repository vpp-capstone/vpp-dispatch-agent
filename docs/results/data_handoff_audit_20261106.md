## 추가한 예측 입력 검사

- 발전소 기준정보에 있는 정확한 18개/3개 ID가 각 시간에 모두 있는지 검사.
- 동일 계획일·대상시간·발전소의 중복을 차단.
- kWh/MWh, 원/kWh/원/MWh 변환과 음수 SMP 보존 확인.
- 각 계획일의 다음 날부터 48시간 연속 구간 검사.
- 발행시각 차이를 보존하고 계획일+대상시간으로 연결.
- 실측 정답 칼럼을 최적화용 출력에서 제외.
- 서로 다른 가용 기간과 실제값이 없는 평가 대상 시간을 명시적으로 집계.

위 항목은 자동 테스트로 동작을 검증하되, 팀의 실제 예측 결과에 대한 실행은 별도다.
