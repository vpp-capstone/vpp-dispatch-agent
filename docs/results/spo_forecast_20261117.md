# SMP 예측: 정확도 기준 vs 운영 수익 기준(SPO+) — 2026-11-17

## 한 줄 결론

같은 LightGBM·같은 특징·같은 매달 재학습에서 학습 손실만 "평균 절대오차"에서 "ESS 운영 수익(SPO+)"으로
바꾸자, 예측 오차는 2.5% 커졌지만 12개 조건 모두에서 20년 NPV가 올랐다 (+0.37 ~ +3.71억 원).
대표 조건(국내 구축비 예시 2MW/8MWh, 낮 판매 상한 2MW)은 NPV 3.87억 → 4.60억, IRR 11.7% → 12.5%.

## 왜 이 실험을 했나

- 초기 연구 방향 문서(`docs/research_direction.md`)의 참고 논문
  Zheng et al., *Smart predict-then-optimize-based model predictive control for Virtual Power Plants
  with battery storage*, Journal of Energy Storage 142 (2026) 119606:
  예측을 오차가 아니라 운영 비용 기준으로 학습하면 오차는 조금 커져도 운영 비용이 평균 10% 줄어든다.
- 같은 질문을 우리 SMP 예측에 적용했다: 예측 정확도보다 운영 목적에 맞춘 예측이 수익에 더 중요한가.

## 진단: 현재 v6 의 문제

대표 조건, 2025년 실행·정산 기준 (v6 결과는 #27 정식 결과와 원 단위까지 같다).

| SMP 예측 | 내일 MAE (원/kWh) | 1년 수익 | 정답 가격 대비 손실 |
|---|---|---|---|
| 정답 가격 | 0 | 11.32억 | 0 |
| v6 | 12.0 | 11.15억 | 1,701만 |
| 전날 같은 시간 가격 | 15.0 | 11.14억 | 1,842만 |

오차는 20% 줄었는데 운영 손실은 8%만 줄었다. 원인은 v6 가 하루 가격 차를 지우는 것이다.

| 2025년 평균 | 실제 | v6 예측 |
|---|---|---|
| 저녁(17~21시) − 낮(10~15시) 가격 차 | 13.2원/kWh | 5.5원/kWh |
| 0원 이하 시간 수 | 152시간 | 0시간 |

평균 절대오차로 학습하면 예측이 평균 쪽으로 몰린다. ESS 는 가격 차이로 돈을 벌기 때문에 최적화가 차익을 작게 보고
ESS 를 덜 쓴다.

## 방법: SPO+ (`src/vpp/spo_forecast.py`)

- 논문(Zheng)은 순부하(제약)를 예측하고 미분 가능한 최적화 층으로 학습한다. 우리는 가격(목적함수 계수)을 예측하므로
  그 방식은 기울기가 대부분 0 이 되고, 신경망으로 바꾸면 손실 효과만 따로 볼 수 없다.
- 그래서 가격 예측용으로 설계된 SPO+ 손실(Elmachtoub & Grigas, Management Science 68(1), 2022)을 LightGBM
  사용자 정의 손실로 넣었다. 모델·특징·재학습 규칙은 v6 그대로다.
- 학습 중 대상일마다 24시간 운영 LP 를 푼다: 태양광 5.7MW, 낮 8~18시 판매 상한 2MW, ESS 2MW/8MWh,
  SOC 10~90%, 효율 95%, 열화비(국내 예시 8MWh 기준 20.83원/kWh), REC 70원/kWh 근사.
- 기울기 = 2 x (실제 가격으로 세운 판매 계획 − (2 x 예측 − 실제) 가격으로 세운 판매 계획) + 0.1 x (예측 − 실제).
  두 계획이 같으면 예측이 틀려도 판단은 그대로라 고치지 않는다. 뒤 항은 정확도를 지키는 앵커다.
- 시작점: 같은 학습 구간의 시간순 4블록 OOF L1 예측. 그 위에 SPO+ 로 60회 더 학습 (학습률 0.05).
- 앵커 강도 0.1 은 2024년 6~12월 검증으로 정했고, 2025년은 한 번만 평가했다.
- 출력은 v6 형식 파일에서 점예측(`smp_hat`)만 바꾼 것이라 `distribution_backtest --forecast` 에 그대로 넣는다.

## 결과 1: 대표 조건 (2025년, 매달 재학습)

| | 내일 MAE | 1년 수익 | 정답 대비 손실 | 20년 NPV | IRR |
|---|---|---|---|---|---|
| 정답 가격 (상한) | 0 | 11.32억 | 0 | 5.79억 | 13.8% |
| v6 | 12.0 | 11.15억 | 1,701만 | 3.87억 | 11.7% |
| 같은 방식 재현 (L1, 매달 재학습) | 12.0 | 11.16억 | 1,668만 | 3.88억 | 11.7% |
| **SPO+ (매달 재학습)** | **12.3** | **11.19억** | **1,287만** | **4.60억** | **12.5%** |

- 월별로 12개월 중 9개월 v6 보다 더 벌었다. 월별 차이 부트스트랩에서 SPO+ 가 v6 보다 못할 확률 0.01%.
- 같은 방식 재현(L1)이 v6 와 거의 같아서, 차이는 손실 함수에서 온다.

## 보조 실험 (요약)

- 학습 고정(2024년 말까지 학습, 2025년 재학습 없음)에서도 같은 결과: L1 3.40억 → SPO+ 4.15억, 12/12 조건 개선.
- 사람이 정한 가중치(하루 가격 차가 큰 시간, 0원 이하 시간)·사후 보정 8종도 v6 보다 NPV 가 높았지만(4.06~4.68억),
  기간마다 순위가 바뀌어 원리적인 방법인 SPO+ 로 정리했다.

## 한계

- 학습용 LP 는 단순화했다: 2024년 이전 태양광은 2025년 같은 월·일·시 값을 빌렸고, REC 는 평균값을 썼다.
  최종 평가는 정식 엔진(계획 → 실행 → 이중가격 정산 → 20년 사업성)으로 했다.
- 평가 기간은 2025년 1년이다.
- 전날 가격을 그대로 쓰면 VPP 몫 NPV 가 5.12억으로 더 높다. 정확도는 낮아도 하루 가격 차를 그대로 두기 때문이며,
  "가격 차 보존이 중요하다"는 같은 결론을 가리킨다. 전체 수익 기준으로는 SPO+ 가 더 높다(11.19억 vs 11.14억).

## 재현

```bash
# 1) SPO+ 예측 (2025년 매달 재학습, 2코어 CPU 기준 약 1시간 40분)
python -m vpp.spo_forecast \
  --base data/processed/forecast/smp_forecast_distribution_2025.csv \
  --generation artifacts/2025/evaluation/solar_improved_2025_with_actual.parquet \
  --out data/processed/forecast/smp_forecast_spo_2025.csv

# 2) 정식 엔진으로 평가 (12개 조건)
python -m vpp.distribution_backtest \
  --generation artifacts/2025/evaluation/solar_improved_2025_with_actual.parquet \
  --fcr data/raw/market/reserve_prices/한국전력거래소_실시간예비력가격_20260630.csv \
        data/processed/market/fcr_hourly.csv \
  --forecast data/processed/forecast/smp_forecast_spo_2025.csv \
  --batteries kr_notice_example,new_2025_bnef --operations forecast_exec \
  --fixed-caps 1.5,2.0,2.5 --dynamic-caps "" --sizes 2:8,4:20 \
  --out data/processed/backtest/spo_grid_2025.csv
```

`--forecast` 를 v6 파일로 바꿔 같은 명령을 돌리면 비교 기준이 나온다.
