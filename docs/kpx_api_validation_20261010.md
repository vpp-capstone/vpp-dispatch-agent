# KPX 태양광 API 실측 확인 — 2026-10-10

## 인증·실제 응답

[한국전력거래소 지역별 시간별 태양광 발전량 정보](https://www.data.go.kr/data/15103243/openapi.do)
실제 호출에 성공했다. 사용자 로컬 `.env`에서 인증키를 읽었으며,
인증키와 인증키가 들어간 요청 URL은 결과 파일이나 문서에 기록하지 않았다.

- 공식 필드 `tradeYmd`, `tradeNo`, `regionNm`, `amgo`로 응답을 받아 변환했다.
- `tradeYmd=20250101` 요청: 전국 408행 중 제주 24행을 받았다.
- 날짜 조건 없는 요청: 전체 834,214행이 있다고 응답했다. 페이지당 10,000행 반환도 확인했다.
- 전국 응답에서 제주만 추출한다. API 공식 명세에는 지역별 요청 필터가 없다.

## 전체 이력 수집 완료

84페이지, 전국 834,214행을 모두 받았고 제주 49,224행을 추출했다.
제주 실제 수록 기간은 2021-01-01~2026-08-21이다. 포털의 업데이트 주기 설명과 별개로
이번에 반환된 마지막 날짜는 8월 21일이다.

- API 제주 키 중복, 빈 수치, 음수: 각각 0개.
- 해당 날짜 범위의 예상 시간은 49,416개이며 192시간이 빠져 있다.
- 누락일: **2024-02-29**, **2026-06-01~06-07** (각 하루 24시간).
- 전체 API 응답 다운로드는 완료됐으나, 실제 관측 달력이 연속적인 자료는 아니다.

2021년은 파일 값 29개가 비어 있어 비교에서 제외된다.
2024년은 API에 윤일 하루가 빠져 8,784시간 중 8,760시간을 비교했다.
API의 2021-01-01~01-15는 하루 전체가 0이지만 파일에는 양수가 있어 별도 검토 대상으로 표시했다.
어느 소스의 값이 옳은지 확인되지는 않았으며, 0을 임의로 결측으로 바꾸지 않았다.

## 2025년 전체 비교

API 원본 캐시에서 2025년 제주를 추출해 기존 KPX 파일 정제본과
`거래일 + 거래시간` 기준으로 비교했다. 양쪽 모두 MWh다.

| 항목 | 결과 |

| 2025년 예상 시간 | 8,760 |

| API 값이 더 작은 시간 | 4,947 |

| 시간별 평균 절대 차이 | 0.363233MWh |

**이 결과는 두 데이터 소스의 차이이며 모델 예측 오차가 아니다.**
수정정산·집계 범위·ESS 처리 등 어떤 이유로 차이가 나는지는 확인되지 않았다.
따라서 API가 더 정확하거나, 나중에 수집했다는 이유로 정정본이라고 판단하지 않는다.

## 현재 선택

- 기존 KPX 파일을 시간별 거래량 Target 후보로 유지한다.
- API는 독립된 비교·추가 기간 자료로 보존한다.
- API 값으로 파일의 결측을 자동 대체하지 않는다.
- 공사 일별 단지 값과도 혼합하지 않는다.

API는 시간 누락과 초기 0값 검토 대상도 있어, 현재 파일 Target을 자동으로 교체할 근거가 부족하다.

## 결과 파일

2025년 검증 결과는 `data/processed/renewable_api_2025/`에 저장했다.

- `jeju_solar_api_2025.csv`: API에서 받은 2025년 제주 값.
- `comparison_report.json`: 1년 비교 결과와 시간 수.
- `api_file_comparison.csv`: 시간별 차이. 파일의 2021~2025년 달력을 함께 보존하므로
  2025년 밖은 비교 대상이 아니다. `comparable=True`로 필터링한다.
- `api_jeju_observations.csv`: API에서 추출한 비교 전 관측값.

전체 조회 원본 캐시와 최종 수집 보고서는 `data/raw/kpx_solar_api/`에 저장한다.
전체 조회의 수집 완료 여부는 `collection_report.json`의 `complete`를 확인한다.
2025년의 모든 시간 확보와 API 전체 이력 다운로드 완료는 구분한다.

수집·비교의 재실행 방법은 [API 실행 문서](kpx_solar_api.md)에 있다.

정제 품질 보고서에 API 상태를 연결하려면 다음처럼 실행한다.

```bash
python -m vpp.build_renewable_history --api-report data/raw/kpx_solar_api/collection_report.json
```
