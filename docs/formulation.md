# ESS 운영계획·비용 평가(초안)

담당: 최적화·대시보드팀.
| 결정할 항목 | 작성할 내용 |
|---|---|
| 대상 범위 | 제주 전체 수요와 실제 운영할 중개사업자 포트폴리오의 관계 |
| 입력 | 수요예측·발전·가격의 출처, 발행시점과 이용 가능 시점 |
| ESS | 용량·출력·효율·SOC 범위와 초기/종료 조건 |
| 목적함수 | 포함할 운영비용·수익 항목 및 단위 |
| 제약 | 에너지 수지·충방전·계통 연결 등 적용할 조건 |
| 기준 방식 | 비교할 운영 방식과 동일 조건 설정 |
| 사후 평가 | 예측으로 정한 계획을 실측에 적용하는 방법 |
| 해결 방법 | 솔버, 성공·불가능·실패 처리, 검증 방법 |

구현 위치: `src/vpp/optimization.py:plan_ess`, `src/vpp/evaluation.py:evaluate_cost`.
`schemas.py`의 `OptimizationRequest`는 예측만 담고 있으니 필요한 입출력 필드 추가 필요.

수력은 현재 필수 범위에서 제외.
