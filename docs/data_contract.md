# 데이터 전처리

## 1. 재생에너지 발전량 (Target)

전력거래소와 제주에너지공사 데이터를 비교해 메인 소스를 고르거나 서로 빈 구간을 메운다.

소스

- 한국전력거래소\_지역별 시간별 태양광 및 풍력 발전량
- 한국전력거래소\_지역별 시간별 태양광 발전량 정보
- 제주에너지공사\_풍력발전기 전력 정보
- 제주에너지공사\_태양광발전기 전력 정보

### 최초 확보한 원본 점검 결과 (2026-10-10, 과거 이력 확장 전)

- KPX 파일: 2025년 제주 태양광·풍력 각각 8,760시간. 해당 기간 누락·중복 없음.
- 제주에너지공사 파일: 태양광·풍력 각각 2026년 2분기 91일. 공사 운영 단지의 일별 자료.
- 두 소스는 현재 확보한 기간이 겹치지 않고 집계 대상과 시간 단위도 다르므로 서로 결측을 채우지 않는다.
- KPX 시간별 전력거래량(MWh)을 Target 후보로 정리했다. 기존 ESS 충·방전이 포함된 거래량이므로 순수 발전량과 구분한다.
- KPX 태양광 API 자료는 미수집이다. API까지 포함한 비교는 남아 있다.

정제 코드: `src/vpp/renewable_targets.py`.
실행 방법과 열 정의는 [Target 정제 문서](renewable_targets.md),
수치와 원본 버전은 [품질 보고서](renewable_target_quality_20261010.md)를 참고한다.
이 결과는 후보 자료 점검이며 아래 공통 전달 형식을 확정한 것은 아니다.

### 팀원 정리를 참고한 과거 이력 확장 (2026-10-10)

- 공개 과거 파일까지 총 52개 수집했다. 단위가 모호한 KPX 중복 파일 1개는 병합에서 제외했다.
- KPX 2021~2025년 제주 시간별 표 43,824행: 태양광 빈 값 29개, 풍력 빈 값 21개를 그대로 보존했다.
- 공사 단지별 일별 표도 확장했다. 2021년 3분기 92일이 빠져 있고, 파일 간 값 충돌은 태양광 171개·풍력 1개 날짜·단지 키다.
- `ts`는 시장 담당자가 정리한 KST 구간 시작 시각에 맞춘 후보 출력이다. 원본 구간 정의는 미확인이므로 감사용 파일에 원본 거래일·시간과 변환 가정을 남겼다.
- 기상 담당의 공사 단지별 위치와 KPX 지역 전체 Target은 집계 대상이 다르다. 단지별 기상과 지역 전체 거래량을 같은 대상의 데이터로 간주하지 않는다.

실행·출력·주의사항은 [재생에너지 팀 전달 문서](renewable_history.md),
노션에 옮길 내용은 [담당 작업 정리](notion_renewable_data_update.md)에 있다.
공통 인터페이스 확정 및 `data.py` 연결은 아직 남아 있다.

### KPX 태양광 API 실측 수집·비교 완료 (2026-10-10)

- 공식 응답 834,214행을 전부 수집하고 제주 49,224행을 추출했다 (2021-01-01~2026-08-21).
- API에서 192시간이 빠져 있다: 2024-02-29와 2026-06-01~07.
- 2021~2025년 파일과 비교 가능한 43,771시간 중 32,395시간의 값이 다르다.
- 2025년은 8,760시간 모두 비교했고 4,947시간이 다르다. 최대 절대 차이는 5.014801MWh다.
- API는 별도 출처로 보존하며 기존 파일 Target을 자동 교체하거나 보간하지 않는다.
- 상세 결과: [API 실측 검증 보고서](kpx_api_validation_20261010.md).

## 2. 전력 시장 및 수요

과거 SMP와 하루 전 예측 SMP의 차이, 전체 수요 대비 공급 여력(출력제어 시점)을 정리한다.

소스

- 제주 지역 계통한계가격(SMP)
- 한국전력거래소\_계통한계가격 및 수요예측(하루전 발전계획용)
- 한국전력거래소\_시간별 제주전력수요
- 한국전력거래소\_제주 전력수급현황

## 3. 날씨·날짜 (Feature)

관측과 예보의 시간축을 맞추고 평일/휴일을 원핫인코딩해 하나의 데이터프레임으로 묶는다.
입찰 마감이 전날 오전 11시이므로 그 이전에 발표된 예보만 사용한다.

소스

- 기상청\_지상(종관, ASOS) 시간자료 — 고산·서귀포·성산·제주, 2021~2025
- 기상청 API허브\_재생에너지 기상정보 — 위·경도 기반, 2021.06~2025.06
- 기상청 API허브\_천리안2A 일사량 — 위·경도 기반, 2019.08~
- 기상청\_단기예보 — 기온·습도·하늘상태·강수확률·풍향·풍속
- 한국천문연구원\_특일정보
- 제주특별자치도\_풍력·태양광 발전소 현황 — 발전소 위·경도
