## 선택 결과

KPX 파일을 **시간별 거래량 Target 후보**로 선택했다. 시간별 운영계획과 맞는 해상도이며 1년치가 연속적으로 존재한다.
공사 자료도 이번 점검에서 결측이 없지만, 다른 대상 설비의 다른 기간 일별 자료이므로 KPX보다 품질이 낮다고 판단한 것은 아니다.
두 소스를 섞거나 서로 보간하지 않았으며 공사 자료는 별도로 보존했다.

KPX 태양광 API는 아직 수집하지 못했다. 따라서 네 소스 전체의 실측 비교가 완료된 상태는 아니다.
거래량의 Target 적합성, 거래시간 구간 의미, 공사 자료 단위를 확인한 후 모델 연결이 필요하다.
