# 제주 하루전 SMP 예측

담당: 데이터&수요예측(가격). 코드: `src/vpp/smp_forecast.py`, 테스트: `tests/test_smp_forecast.py`

## 무엇을 내보내나

입찰 마감인 **D-1 11시**에 내일(D)과 모레(D+1)의 시간별 제주 하루전 SMP 48개를 예측한다.
최적화(`optimization.run_rolling`)가 48시간 창을 풀고 앞 24시간만 확정하기 때문이다.

팀 공유용 결과는 제주 기상 피처([smp_weather_features.md](smp_weather_features.md))를 붙여 만든다.

```bash
W=data/processed/weather/jeju_renewable_weather_features.csv
python -m vpp.smp_forecast --weather $W --variants                   # 11시 입찰용 + 비교용 가격
python -m vpp.smp_forecast --weather $W --variants --issue-hour 18   # 18시 재계획용
python -m vpp.smp_forecast                                           # 기상 없이 (시장 자료만)
```

입력은 `data/processed/market/`의 `market_hourly.csv`, `smp_forecast_hourly.csv`(vpp.market 결과).
출력은 `data/processed/forecast/`.

| 파일 | 내용 |
| --- | --- |
| `smp_forecast.csv` | 발행일마다 48행. `issue_date`, `issue_time`(D-1 11:00+09:00), `horizon`(1=내일, 2=모레), `lead_hour`(발행 시각부터 대상 시각까지 시간 수, 13~60), `target_time`(KST 구간 시작, +09:00), `smp_hat`(원/kWh), `smp_hat_krw_per_mwh`, `p_low`(0원 이하 확률), `smp_b1`(비교 기준), `smp_actual`(사후 확인용), `trained_until`, `train_rows` |
| `smp_metrics.csv` | 내일·모레, 연도별 MAE·RMSE와 저가 경보 적중 |
| `smp_forecast_b1.csv`, `smp_forecast_actual.csv` | `--variants`. 같은 형식에서 `smp_hat`만 전날 가격(B1) / 실제 가격(완전예측 상한)으로 바꾼 비교용 입력. `price_source` 열로 구분 |
| `smp_forecast_18*.csv`, `smp_metrics_18.csv` | `--issue-hour 18`. 발행 D-1 18:00, `lead_hour` 6~53. 내일(D)은 18시에 공표된 실제 가격, 모레(D+1)만 재예측 |

ESS 수익 비교(예측 가격 / 전날 가격 / 실제 가격)는 세 파일을 `forecast_backtest --smp`에 차례로 넣으면 된다.

최적화에 넣을 때는 `window_for_issue(forecast, 발행일)`이 그 발행일의 48시간을
`ts`, `price_krw_per_mwh`로 돌려준다. 계획은 예측 가격으로 세우고, 수익은 `smp_actual`로 정산한다.

## 시점 규칙 (D-1 11시에 알 수 있는 것만)

18시 발행은 하루전 SMP·육지 SMP만 하루 더(D까지) 쓰고, 나머지 규칙은 11시와 같다(수요 실적은 D-2까지).

| 자료 | 사용 범위 | 이유 |
| --- | --- | --- |
| 하루전 SMP | 발행일 D-1까지 | D-1 가격은 D-2 18시에 공표 |
| 육지 SMP | D-1까지 | 같은 규칙 |
| 수요 실적 | D-2까지 | D-1 실적은 11시에 일부만 있음 |
| KPX 하루전 수요예측 `fcst_jeju` | **기본 제외** | 공표 시각 미확인. 제주 시범사업 발전계획 타임라인([별표 34](https://marketrule.kpx.or.kr/lmxdata/attach/2025/5/upload_5127126665285383397_p194.pdf))에 수요 관련 시각은 16시 검토뿐이고, [공공데이터포털 API 설명](https://www.data.go.kr/data/15131225/openapi.do)은 "하루 1회 23시경 갱신". 11시 전 공표가 확인되면 `--use-fcst` |
| 기상 지표 | `available_at <= 발행 시각`인 예보 중 가장 최근 것, 48시간 이내 | 발전량 담당이 넘기는 발표·가용 시각 기준 |

기상 지표 CSV는 `available_at`, `target_ts`(KST)가 꼭 있어야 한다. 이 두 열과 `issued_at`,
`lead_hours`, 품질 열(이름에 coverage·capacity·quality·reliab·confidence 포함)을 뺀 숫자 열이 입력이 된다.
생성 방법과 32개 피처 정의는 [SMP 예측용 제주 기상 피처](smp_weather_features.md)에 정리한다.

## 모델

- 특징: 시간·요일·월·연중위치·공휴일, 발행일 같은 시간 가격, 그 전날 가격, 대상일 7일 전 가격,
  발행일 평균·최저·최고·0원 이하 시간 수, 육지 SMP 평균, 수요 실적
- 추가 특징(`EXTRA_FEATURES`): 최근 3·7일 같은 시간 중앙값, 대상일과 같은 요일 유형(평일/토/일·공휴일)
  가장 최근 날의 같은 시간 가격, 육지 SMP 최근 이틀 같은 시간 값. 2024년 선택 구간에서 내일 MAE
  14.75 → 14.29, 모레 16.24 → 15.49로 좋아져 채택했다. 기존 특징만 쓰려면 `--base-features`
- 내일·모레 각각 LightGBM(L1 손실) 회귀 + 0원 이하 확률 분류기
- 매달 1일 발행분부터 그 시점에 정답이 공표된 자료(2021-01 ~)로 다시 학습
- 비교 기준 B1: 발행일(D-1) 같은 시간 가격 그대로. 모레에 대해서는 이틀 전 가격이 된다.

모델 선택 근거 (2024년으로 고르고 2025년으로 평가): LightGBM, LEAR(시간별 LASSO), ExtraTrees,
Ridge, MLP 중 LightGBM이 두 해 모두 MAE가 가장 낮았다. 한 번만 학습하는 것보다 매달 재학습이 나았고,
최근 저가 이력·최근 가중치·전날 오전 실시간가격은 효과가 없었다.

## 결과 (원/kWh)

MAE. 모델 열은 기상 피처를 붙인 최종 결과이고, 괄호는 (기상 없음 / 추가 특징 전) 값이다.

| 발행 | 대상 | 기간 | B1 | 모델 | 0원 이하 제외 |
| --- | --- | --- | --- | --- | --- |
| 11시 | 내일 | 2024-06 ~ 12 | 14.69 | 10.91 (11.26 / 11.40) | 9.52 |
| 11시 | 내일 | 2025 | 15.01 | 12.02 (12.14 / 12.44) | 9.89 |
| 11시 | 모레 | 2024-06 ~ 12 | 18.27 | 11.74 (11.98 / 12.29) | 10.44 |
| 11시 | 모레 | 2025 | 18.61 | 13.08 (13.15 / 13.56) | 10.93 |
| 18시 | 모레 | 2024-06 ~ 12 | 14.44 | 10.84 (11.07) | 9.59 |
| 18시 | 모레 | 2025 | 15.01 | 12.10 (12.16) | 9.97 |

- 18시 발행의 B1은 18시에 공표된 D일 같은 시간 가격이다. 18시 재계획의 뒤 24시간(D+1) 가격 오차는
  11시 모레 예측보다 2025년 기준 약 7.5% 작다(13.08 → 12.10).
- 기상 피처는 평균 오차를 0.5~1% 줄이는 데 그치지만 0원 이하 시간 탐지를 크게 늘린다
  (2025년 152시간 중, `p_low >= 0.5` 기준 적중/헛경보).

| 발행·대상 | 기상 없음 | 기상 있음 |
| --- | --- | --- |
| 11시 내일 | 5 / 12 | 18 / 22 |
| 11시 모레 | 4 / 13 | 10 / 19 |
| 18시 모레 | 4 / 10 | 12 / 25 |

- 기상 피처 선택: 2024년 1년 전체로 "기상 없음 / 있음" x "학습 시작 2021 / 2023"을 비교했고,
  기상 있음 + 2021년부터가 11시 내일·모레 평균 MAE가 가장 낮아(14.52, 2023년부터는 14.61) 채택했다.
  2021~2022년 표본은 기상 값이 비어 있는 채로 학습한다(LightGBM이 빈 값을 따로 처리).

## 한계

- 0원 이하 시간(2025년 152시간, 1.7%)은 회귀로는 거의 예측하지 못한다. 학습 기간의 0원 이하 사례가
  2024년 이후에만 있어서다. 기상 피처를 붙여도 분류기 `p_low`가 잡는 것은 152시간 중 10~18시간이고
  경보의 절반 이상이 헛경보다. `p_low`는 참고용이다.
- 기상 지표는 2023년부터만 있다(2023-05-24 하루 없음). 그 이전 학습 표본은 기상 값이 비어 있다.
- 최종 평가는 오차가 아니라, 이 예측으로 세운 ESS 계획을 실제 가격으로 정산한 수익으로 한다.
