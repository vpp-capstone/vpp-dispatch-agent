# 태양광 18개소·풍력 3개 단지 데이터 확인 결과

기준일: 2026-10-30

## 1. 최종 판단

- 태양광 18개소 데이터는 2023~2025년 발전량 모델 정답으로 사용 가능하다.
- 성산·한경·상명 풍력도 2023~2025년 정답으로 사용 가능하지만 단위·중복·결측·이상치 처리가 필요하다.
- 태양광 파일에 포함된 기상값은 ASOS 관측값이므로 예보 기반 모델 입력으로 사용하지 않는다.
- 태양광 파일에는 발전소 주소나 좌표가 없어서 실제 좌표를 완전히 확정할 수 없다. 대신 동일 기상값 기준의 3개 권역 프록시를 사용할 수 있다.
- 성산과 상명에는 별도 ESS 설비가 있는 것으로 확인된다. 발전실적 파일에 ESS 충·방전이 포함되는지는 공개 설명만으로 확정할 수 없다.

### 태양광 위치 확인 수준

제주 발전소 현황 파일과 발전소명·설비용량을 대조했을 때 일부 시설은 행정지역을 유력하게 연결할 수 있었다.

- 금오름: 제주시 한림읍
- 남원: 서귀포시 남원읍
- 미리내: 서귀포시 남원읍
- 봉성: 제주시 애월읍
- 수망: 서귀포시 남원읍 후보
- 제주탑: 서귀포시 대정읍
- 평대: 제주시 구좌읍
- 표선: 서귀포시 표선면

하지만 공개 발전소 현황의 이름이 마스킹되어 있고 동일 용량 시설도 존재하므로 이를 정확한 개별 발전소 좌표로 확정하지 않는다. 위치 품질은 `regional_proxy`로 기록한다.

### 태양광 ESS 여부

- 공식 데이터 설명에는 ESS 포함 여부가 적혀 있지 않다.
- 명백한 야간 방전 패턴은 확인되지 않았다.
- 1~6시와 22~24시 중 0이 아닌 값은 모두 6시 구간에서만 나타났고 최대 7.92kWh로 작았다. 이는 여름철 일출 후 발전으로 설명 가능하다.
- 따라서 현재 자료에서는 ESS 방전 신호가 뚜렷하지 않지만, `ESS 미포함`이라고 공식 확정할 수는 없다.

## 3. 성산풍력

### 기본 정보

- 위치 프록시: 서귀포시 성산읍 수산리
- 좌표: 위도 33.44305, 경도 126.86478
- 공식 설비용량: 20MW
- 단계 1: 12MW, 1~6호기
- 단계 2: 8MW, 7~10호기
- 기간: 2013-01-01~2026-03-31
- 시간값 공식 단위: kWh

### 정제 규칙

- 같은 시간의 단계 1과 단계 2를 합산한다.
- 합산 후 1,000으로 나눠 MWh로 변환한다.
- 두 단계 중 하나라도 결측이면 합계를 계산하지 않고 해당 시간을 결측 처리한다.

### 품질 문제

- 단계별 시간값 결측: 6건, 모두 2024~2025년에 존재
- 날짜·단계 중복: 없음
- 음수: 없음
- 일별 총량과 24개 시간값 합계가 1kWh보다 크게 다른 행: 476건
- 이 중 큰 차이는 소수이며, 모델 정답은 일별 총량이 아니라 시간별 값으로 구성한다.
- 2023~2025년에 합산출력이 20MW를 넘는 시간이 3건 있다.
- 가장 큰 값은 2023-02-24의 24.744MWh로 명백한 이상치 후보이므로 학습에서 제외하거나 결측 처리한다.

### ESS 확인사항

한국남부발전 설비현황에는 성산ESS 2MW가 별도 설비로 기재되어 있다. 성산풍력 발전실적이 풍력발전만 나타내는지, ESS 충·방전이 포함된 송전량인지는 공개 파일 설명만으로 확정할 수 없다.

## 5. 상명풍력

### 기본 정보

- 위치: 제주시 한림읍 금악리
- 좌표 프록시: 위도 33.359982, 경도 126.3017587
- 공식 설비용량: 21MW, 3MW×7기
- 공식 부대 ESS: PCS 2MW, 배터리 7.3MWh
- 기간: 2023-01-01~2026-03-30
- 2023~2025년 날짜·시간 중복 없음
- 2023~2025년 결측 없음
- 2026년에 하루 전체 결측 3일 존재

### 단위 문제

공식 설명은 시간값을 kWh라고 안내하지만 원본 값은 2025-02-01을 경계로 정확히 약 1,000배 스케일이 바뀐다.

- 2025-01-31까지: Wh로 해석하여 1,000,000으로 나눠 MWh 변환
- 2025-02-01부터: kWh로 해석하여 1,000으로 나눠 MWh 변환

이 변환을 적용하면 다음과 같이 물리적으로 타당하다.

- 최대 시간 발전량: 20.109MWh
- 2023년 발전량: 31,331.211MWh
- 2024년 발전량: 30,872.202MWh
- 2025년 발전량: 31,654.927MWh

단위 전환은 데이터 값으로 강하게 확인되지만 공식 설명과 다르므로 `unit_regime_inferred=true`를 남기고 가능하면 제공기관에 확인한다.

### ESS 확인사항

상명풍력에는 2MW/7.3MWh ESS가 설치되어 있다. 파일 설명은 값을 송전량이라고 표현하므로 ESS 충·방전이 값에 포함됐을 가능성을 배제할 수 없다. MILP에서 별도 ESS를 다시 최적화하면 효과를 중복 계산할 수 있으므로 제공기관에 다음을 확인한다.

> 상명풍력 시간별 송전량은 풍력 터빈 순발전량인가, 아니면 상명 ESS 충·방전을 반영한 계통 송전량인가?

## 6. 모델에 사용할 최종 정답

### 태양광

- 18개 발전소별 `계량전력량 / 1,000 = MWh`
- 발전소별 `MWh / 설비용량MW = 시간 이용률`
- 학습기간: 2023-01-01~2025-12-31
- 파일의 관측 기상열은 입력에서 제외
- 3개 권역의 과거 예보기상을 입력으로 연결

### 풍력

- 성산: 단계 1+2 합계 후 MWh 변환
- 한경: 단계 1+2 합계 후 MWh 변환
- 상명: 단위 구간을 나눠 MWh 변환
- 두 단계 중 하나라도 결측인 시간은 합계 결측
- 중복 충돌과 설비용량 초과 이상치는 학습에서 제외
- 세 단지 합계가 연구용 VPP 풍력 정답
