# 기상예보 기반 발전량 예측 모델 결과

## 학습 및 검증 계약

- 정답 시각 기준 2023년: 학습
- 정답 시각 기준 2024년: 검증 및 조기 종료
- 2025년: 수집 완료 후 최종 테스트에만 사용
- 유효 정답: `label_is_valid == True`
- 같은 실제 발전 시각이 학습과 검증에 동시에 포함되지 않도록 `valid_time_kst` 연도로 분할
- 발전량 지연값은 입찰 시점 누수 위험 때문에 1차 모델에서 사용하지 않음

현재 수치는 2024년 검증 결과이며 최종 테스트 결과가 아니다.

## 모델

기준선은 2023년의 발전소·월·시간대별 평균 이용률이다. 기상 모델은 발전원별
LightGBM 회귀모델이며 이용률을 예측한 뒤 `[0, 1]`로 제한하고 설비용량을 곱해 kWh로
복원한다. 태양광은 태양고도가 0도 이하이거나 예보 일사량이 0이면 0kWh로 처리한다.

## 2024년 포트폴리오 검증 결과

| 발전원 | 모델 | 48시간 nMAE | 24시간차 nMAE | 48시간차 nMAE |
|---|---:|---:|---:|---:|
| 태양광 | 기준선 | 6.2063% | 6.2061% | 6.2064% |
| 태양광 | LightGBM | 3.7941% | 3.6679% | 3.9202% |
| 풍력 | 기준선 | 13.8128% | 13.8128% | 13.8128% |
| 풍력 | LightGBM | 6.4347% | 6.1199% | 6.7495% |

- 태양광 포트폴리오 nMAE 개선율: 38.87%
- 풍력 포트폴리오 nMAE 개선율: 53.42%
- 태양광 최적 반복: 175
- 풍력 최적 반복: 106

48시간차 예측은 두 발전원 모두 24시간차보다 오차가 크며, MILP에서 이 차이를 예측
불확실성으로 고려해야 한다.

## 주요 피처

태양광 상위 피처:

1. 태양고도
2. 주야 여부
3. 시간 주기
4. 하향 단파복사량
5. 계절 주기
6. 전운량

풍력 상위 피처:

1. 80m 풍속
2. 80m V 바람성분
3. 계절 주기
4. 기온
5. 발전단지 ID
6. 풍향 주기성분

상위 피처는 인과관계가 아니라 현재 모델에서의 분할 이득 기준이다.

## 파일

- `solar_lightgbm.joblib`, `wind_lightgbm.joblib`: 모델·피처·범주 매핑 묶음
- `solar_validation_predictions.parquet`: 2024년 태양광 검증 예측
- `wind_validation_predictions.parquet`: 2024년 풍력 검증 예측
- `generation_model_metrics.csv`: 발전원·모델·예측거리·집계수준별 지표
- `generation_asset_metrics.csv`: 발전소별 지표
- `solar_feature_importance.csv`, `wind_feature_importance.csv`: 피처 중요도
- `training_summary.json`: 학습 범위·최적 반복·전체 지표

예측파일의 고유키는 `asset_id + issue_time_utc + valid_time_utc`다. 포트폴리오 예측은
동일 `issue_time_utc + valid_time_utc`의 발전소별 예측 kWh를 합산한다.

## 재학습

.\.venv\Scripts\python.exe .\train_generation_models.py

현재 모델로 먼저 최종 테스트한다. 최종 성능을 확정한 뒤 2023~2024년 전체로 재학습하여
운영용 모델을 만든다.
