# 1단계 시간 정산 검산 자료

이 폴더의 실행량·시장가격·급전·입찰·FCR 값은 **모두 합성 자료**다. 실제 시장 실적이나 실제
입찰하한가격을 뜻하지 않는다. 2024-06-01에 현행 규칙을 가상 적용하는 예제로, 결과에는
`current_rule_counterfactual`이 기록된다. 손실계수는 1, REC·열화비는 0으로 가정한다.
REC 0은 실행 CSV에 명시하고, 열화비 0은 예제의 `--ess` 설정으로 명시한다.

저장소 루트에서 실행:

```bash
.venv/bin/python -m vpp.hourly_settlement \
  --execution data/sample/settlement_hourly/execution.csv \
  --market data/sample/settlement_hourly/market.csv \
  --dispatch data/sample/settlement_hourly/dispatch.csv \
  --ess config/ess_v0.yaml \
  --outdir data/processed/settlement/stage1_sample
```

`hourly_settlement.csv`를 아래 표와 비교한다. 단위는 원이다.

| KST 시간 | 확인 항목 | 에너지 수익 | 페널티 | 차감 후 수익 |
|---|---|---:|---:|---:|
| 00시 | 판매 편차 -2 MWh, 급전 편차 0 | 700,000 | 0 | 700,000 |
| 01시 | 1.5% 초과 발전 | 760,000 | 40,000 | 720,000 |
| 02시 | 1.5% 허용오차 경계 | 722,500 | 0 | 722,500 |
| 03시 | 6% 초과 발전 | 820,000 | 1,000 | 819,000 |
| 04시 | 음수 실시간 가격·초과 발전 | 1,032,000 | 51,250 | 980,750 |
| 05시 | 감발 지시 조건·미달 면제 | 550,000 | 0 | 550,000 |
| 06시 | 6% 미달 발전 | 550,000 | 2,000 | 548,000 |
| 합계 | 7시간 중 페널티 발생 4시간 | 5,134,500 | 94,250 | 5,040,250 |

01시 손계산:

```text
하루전 수익 = 10 MWh × 100 원/kWh × 1,000 = 1,000,000 원
편차 정산 = (8.4 − 10) × 150 × 1,000 = -240,000 원
허용오차 = 발전설비 10 MW × 1.5% × 1시간 = 0.15 MWh
허용범위 밖 물량 = (8.4 − 급전 목표 8) − 0.15 = 0.25 MWh
단가 = max(150 − (-10), 0) + 0 = 160 원/kWh
페널티 = 0.25 × 160 × 1,000 = 40,000 원
최종 = 1,000,000 − 240,000 − 40,000 = 720,000 원
```

`summary.json`의 순수익이 5,040,250원이고, 페널티 발생 4시간·0원 3시간·누락 0시간인지
확인한다. `daily_settlement.csv`의 `full_day_coverage`는 7시간 예제이므로 False가 정상이다.
7시간을 하루 전체 결과로 해석하지 않는다.

결측 처리도 확인하려면 `--dispatch`를 빼고 **다른 출력 폴더**로 실행한다. 에너지 수익은 그대로
5,134,500원이고, 페널티 누락 7시간·페널티와 순수익 null이 정상이다. 급전 자료가 없는 경우를
페널티 0원으로 처리하지 않는지 확인하는 예제다.
